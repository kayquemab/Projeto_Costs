# Costs - Hora de Codar
Projeto desenvolvido durante o curso **Hora de Codar**, ministrado por Matheus Battisti, para praticar **React.js** e conceitos de gerenciamento de projetos e orçamentos.

### 📌 Sobre

O **Costs** é uma aplicação em **React** para gerenciar projetos e orçamentos usando **JSON-Server**.
